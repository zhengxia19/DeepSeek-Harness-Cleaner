三、执行过程与退出码
----------------------------------------
1) 首次引导（下载 + 安装）
   命令：.\scripts\bootstrap.ps1
   结果：下载 dotnet-install.ps1；SHA-256 校验通过；
         dotnet-install: Downloaded file https://builds.dotnet.microsoft.com/dotnet/Sdk/10.0.402/dotnet-sdk-10.0.402-win-x64.zip size is 300755826 bytes
         dotnet-install: Installed version is 10.0.402
   退出码：1（首次运行）——原因：脚本在调用官方脚本后用 $LASTEXITCODE 判断失败，而官方脚本是 PowerShell 脚本、不设置 $LASTEXITCODE。
   修复：移除该退出码判断，改由“安装后 SDK 目录存在性 + 版本提取”判定成功（见 bootstrap.ps1 第 2/3 步）。

2) 复跑引导（幂等 + 写 global.json）
   命令：.\scripts\bootstrap.ps1
   输出：安装脚本 SHA-256 校验通过 / 已存在 10.0.402 跳过下载 / global.json 固定 SDK 版本：10.0.402 / dotnet --version: 10.0.402
   退出码：0

3) 版本稳定性核验（官方发布记录 + 下载包哈希）
   命令：Invoke-RestMethod https://raw.githubusercontent.com/dotnet/core/main/release-notes/10.0/releases.json
   结果：SDK 10.0.402 属于官方发布 release-version=10.0.13，release-date=2026-10-13，security=True（非 preview）
   官方 win-x64 zip：https://builds.dotnet.microsoft.com/dotnet/Sdk/10.0.402/dotnet-sdk-10.0.402-win-x64.zip
   官方 SHA-512：ae4fd528cb7e9f6af6aaf7de36715a69f761f183744f1bb3025d19f5a92447090ec561410e46266c1d10a63781ed6f3de771760bc76c876d87daabc367b898cd
   本地下载实测：size=300755826 bytes；Get-FileHash SHA512 = ae4fd528cb7e9f6a...367b898cd；hash match: True
   验证后已删除该临时 zip（.artifacts\dotnet-sdk-10.0.402-win-x64.zip，removed=True）

4) 验收：无全局 SDK 的用户模式 shell 中 dotnet --info
   命令：pwsh -NoProfile -File .artifacts\accept-t02-inner.ps1
         （脚本内先把 PATH 中 *Program Files\dotnet* 条目移除并清除 DOTNET_ROOT/NUGET_PACKAGES，再 dot-source scripts/enter-env.ps1）
   关键输出：
     which dotnet (before enter-env): （空，即无全局 SDK 可用）
     which dotnet (after enter-env): D:\Code\DeepSeek-Harness-Cleaner\.dotnet\dotnet.exe
     .NET SDK Version: 10.0.402 / Base Path: D:\...\.\dotnet\sdk\10.0.402\
     .NET runtimes installed: Microsoft.NETCore.App 10.0.13、Microsoft.WindowsDesktop.App 10.0.13、Microsoft.AspNetCore.App 10.0.13（均在 .dotnet\shared）
     Environment variables: DOTNET_ROOT / DOTNET_MULTILEVEL_LOOKUP=0 / NUGET_PACKAGES 未出现在进程变量列表中的 NUGET_PACKAGES 行（见下条说明）
   退出码：0
   说明：dotnet --info 的“Environment variables”段落列出 DOTNET_CLI_HOME、DOTNET_CLI_TELEMETRY_OPTOUT、DOTNET_MULTILEVEL_LOOKUP、DOTNET_NOLOGO、DOTNET_ROOT、DOTNET_SKIP_FIRST_TIME_EXPERIENCE；NUGET_PACKAGES 由 enter-env.ps1 设为 D:\Code\DeepSeek-Harness-Cleaner\.nuget\packages（dotnet --info 未列出该项，属 dotnet 自身显示范围，非未生效）。

5) 验收：退出 shell 后系统 PATH 与全局 NuGet 目录未变
   基线（运行脚本前采集，存于 .artifacts\base-machine-path.txt / base-user-path.txt）
   命令：[Environment]::GetEnvironmentVariable('PATH','Machine'|'User') 与 NUGET_PACKAGES / DOTNET_ROOT 的 Machine/User 值比对
   结果：
     Machine PATH unchanged: True
     User PATH unchanged:     True
     NUGET_PACKAGES Machine/User: [] []
     DOTNET_ROOT Machine/User:    [] []
     新开 pwsh（未 dot-source enter-env）的 $env:NUGET_PACKAGES: []（空）
     全局 NuGet 目录 %USERPROFILE%\.nuget\packages 仍存在（83 个子目录，本任务未向其写入：全程未执行 restore/构建）
   未使用 setx；未改注册表；未请求管理员权限。

6) 验收：SDK 版本与 global.json 一致，且固定生效
   命令：读取 global.json 与 .dotnet\sdk 目录名比对
   结果：global.json=10.0.402，installed=10.0.402，match=True
   负向测试：临时把 global.json 版本改为 10.0.999 后执行 dotnet --version
     退出码：1；输出 “A compatible .NET SDK was not found. Requested SDK version: 10.0.999”
     随后已恢复 global.json 为 10.0.402（restored 输出已核对）

四、验收标准逐条结论
----------------------------------------
1. 未安装全局 SDK 的用户模式 shell 中 dotnet --info 成功 → PASS（见 4，退出码 0；PATH 已移除全局 dotnet 目录）
2. 退出该 shell 后系统 PATH 与全局 NuGet 目录未变 → PASS（见 5）
3. SDK 版本与 global.json 一致 → PASS（见 6，且 rollForward=disable 使不匹配直接失败）
4. 仅进程级环境变量、无 setx、无系统 PATH 改动、无管理员权限 → PASS（见 5；enter-env.ps1 只赋值 $env:*）
5. 安装脚本来自官方端点且经哈希核验；SDK 包经官方 SHA-512 核验 → PASS（见 2、3）
