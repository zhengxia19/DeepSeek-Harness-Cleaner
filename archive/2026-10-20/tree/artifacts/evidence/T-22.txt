  - 失败路径（取消 CANCELED / IO_FAILURE / 校验 ZIP_VERIFY_FAILED / 结构损坏）一律移除临时 zip，不返回成功，不触碰旧备份。
  - VerifyZip(zipPath, manifest)：对已发布 zip 复验（SEC-03），只读。

## 验收标准逐项
- 损坏不返回成功：VerifyZip 对单字节破坏（3 个独立偏移 XOR 0xFF）均 ZIP_VERIFY_FAILED；破坏后校验失败、还原后通过 → PASS
- 磁盘满/IO 失败不返回成功：目标目录缺失 → IO_FAILURE 且无残留；目标为已存在目录 → IO_FAILURE 且无临时残留（模拟 IO 异常路径）→ PASS
- 目标已有文件不返回成功：TARGET_EXISTS，哨兵旧备份字节不变，无临时残留 → PASS
- 进程取消不返回成功：预取消 token → CANCELED，无目标、无临时残留 → PASS
- 完成 ZIP 解压后每份原文件与原 SHA 一致：CreateBackup_PublishesZip_AndExtractedBytesMatchOriginals
  （解压 3 条目字节与原文件逐一相等，且等于 manifest 记录的小写 SHA-256）→ PASS
- 校验 entry 字节 SHA/数量/长度后无覆盖发布：VerifyZipContent 先于发布执行；发布前复验 + File.Move(overwrite:false) → PASS
- 失败移除临时 zip：所有失败用例断言 backupDir 无 *.tmp-* 残留 → PASS
- 删前文件变化：CreateBackup_DetectsFileChangedAfterManifestBuild → ZIP_VERIFY_FAILED，无发布 → PASS
- TC-09“失败没有清理副作用”：各失败路径仅删除自产临时文件，原数据文件未触碰 → PASS

## 排障记录（真实）
- using ZipArchive zip; 后在 try 内赋值 → CS0210/CS1656/CS0165；改为普通声明 + using(zip) 块。
- 小 zip 单字节破坏偏移可能落在 local header（.NET 读取元数据以 central directory 为准，忽略 local 名字段）导致校验仍通过；
  附件夹具改 4KB 伪随机字节使偏移落入条目数据流后稳定失败。
