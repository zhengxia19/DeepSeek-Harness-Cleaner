## 改动清单
- src/DeepSeekHarnessCleaner.Infrastructure/SessionHeaderReader.cs
  ParseHeaderLine 改为真实契约（依据 M-01 DIAG-scan-coverage/DIAG-event-format 实测）：
  * type=="session"（旧假设 type:"header" → HEADER_MISSING，安全失败不放宽门禁）
  * id：非空字符串，缺失/空 → HEADER_ID_MISSING
  * version：JSON 数值 int；缺失/非数值/非整数/<0 → HEADER_VERSION_INVALID；>4 → Unsupported + HEADER_VERSION_UNSUPPORTED
  * createdAt：仅接受 epoch-millis JSON 数值（ValueKind==Number + TryGetInt64）；字符串/缺失/非整数/超 DateTimeOffset 范围 → HEADER_DATE_INVALID
  * cwd 等其余字段（isSeeded/delegationDepth/agentPreset…）可选、不校验语义；cwd 仅约束 JSON 类型
- src/DeepSeekHarnessCleaner.Infrastructure/SessionEventReader.cs：KnownEventTypes "header"→"session"（随 header 契约的最小词汇更名；事件词汇其余部分留 M-03）

- tests/Fixtures/FixtureFactory.cs：HeaderLine 输出真实格式；ISO 参数换算 epoch-millis，不可解析时写成 JSON 字符串（保留 HEADER_DATE_INVALID 负向用例语义）

- tests/EventReaderTests.cs：EventType 断言 ["header","message"]→["session","message"]（2 处）
