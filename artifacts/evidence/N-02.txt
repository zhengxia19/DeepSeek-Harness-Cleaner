== 改动范围（边界(改)内）==
- src/DeepSeekHarnessCleaner.UI/MainForm.cs：
  * 列序改为 [check(DataGridViewCheckBoxColumn)][num][id][project][created][origin][size][format][status][archive]。
  * 勾选列：SortMode=NotSortable、可编辑；序号列：只读、NotSortable、绑定顺序 1 基赋值。
  * 网格级 ReadOnly=false + 除 check 外全部列 ReadOnly=true（WinForms 陷阱：列级 ReadOnly=false 的 setter 会移除属性并回退到网格级 true，无法覆盖；已用冒烟断言 ro=False/ro=True 锁定）。
  * EditMode=EditOnEnter + CurrentCellDirtyStateChanged→CommitEdit：单击勾选即提交并触发 CellValueChanged。
  * 删除按钮启用条件 = 存在勾选行（UpdateDeleteButtonEnabled，经 CellValueChanged/SelectionChanged/BindSessions 刷新）；OnDeleteClick 取勾选行 Tag（按列表顺序），不再用 SelectedRows；预览仍按行选中（RequestPreviewAsync 不变）。
  * project/created/size 三列 AutoSizeMode=AllCells；BindSessions 后 EnsureContentColumnWidths 兜底：逐行 TextRenderer.MeasureText + 样式内边距 + 6px，含表头，不足则切 None 并加宽（AllCells 只测已显示行，虚拟化行会漏算）。
  * 多会话预览提示文案改为“删除按勾选行”。
- src/DeepSeekHarnessCleaner.UI/MainForm.Smoke.cs：
  * GridMatches 增加：勾选列初始未选（Value is false）、序号列 = 绑定顺序 i+1。
  * 新增断言：列序字符串断言；勾选列=复选框列/不可排序/可编辑 + 序号列只读/不可排序；三列宽度 ≥ 全行最长内容首选宽度（含表头）；删除计划仅含勾选两会话（目标路径集合与独立构建的 expectedPlan 一致）。
  * TC-08 重写为勾选语义：勾选两行启用删除；按 size 列排序后勾选仍指向原会话 + 序号随行（(id,num) 对排序前后 SequenceEqual）；取消勾选禁用删除。
  * 删除流程（RunActionsChecks/TC-16）由行选中改为设置勾选；收尾复位勾选。
  * “删除按钮初始禁用（未选择会话）”更名“（未勾选会话）”。
- scripts/smoke-win10.ps1：WIN10-01 期望冒烟断言数 74→79。
- 边界(不改)遵守：SessionSummary/服务层、筛选逻辑、行 Tag 绑定机制均未改动；无新增网络/遥测。
