一、实施摘要
- ReadableExport.Export(ReadableExportInput)：复用 LegacyPreview（代际选择/元数据/MetadataOnly 退化）与 TranscriptProjector 投影，产出 UTF-8 Markdown + 机器可读 JSON 概览（schemaVersion=1）。
- Markdown：标题固定声明“不是恢复备份”；exportIncomplete 与不完整原因逐条列出；消息正文置于代码块，围栏长度 = 正文最长反引号串 + 1（≥3），保证含 ```/````/~~~/中文/换行的正文不破坏结构、可逐字节往返；不完整事件以引用块输出；附件节标注 存在/缺失/状态未知。
- JSON：Utf8JsonWriter + UnsafeRelaxedJsonEscaping（保留 UTF-8 中文，控制字符安全转义）；含 exportIncomplete、incompleteReasons、generations、attachments(state)、projection(items/truncated/incompleteCount)。
- exportIncomplete=true 触发条件：未知/不完整事件、预览上限截断（超限）、附件缺失、附件磁盘清单不可判定、MetadataOnly（未确证代际或最高代际不可读）。
- 离线：ReadableExport.cs 无 HttpClient/Socket/File/Directory 调用（grep 0 命中），纯内存字符串变换。
